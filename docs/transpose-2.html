Transposing Instruments: Reference & Memory Test

Learn the transpositions you need for reading scores. Filter the list, then select Test my memory to practise. Every example starts with a written C4 (middle C).

Remember: the key in an instrument's name tells you what a written C sounds as (ignoring octaves). For example, an instrument in B♭ sounds B♭ when it reads C. Octave displacement matters when reading the exact register of a score.
