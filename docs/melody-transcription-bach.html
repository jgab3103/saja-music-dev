Baroque Transcription Lab

Hear the texture, isolate an individual contrapuntal voice, and transcribe a short phrase—or work through the complete piece. The exercise is generated from the actual MusicXML pitches, durations, rests and voice assignments.

Select a work from the repertoire library, then choose which voices and measures to transcribe. More works can be added to the repertoire list as new JSON files are prepared.

1. Choose what to transcribe

Select one voice to focus on a single contrapuntal line, or several to transcribe a fuller texture. Voice numbers follow the MusicXML source.

Preparing repertoire…

2. Listen

Choose which voices you hear. All parts gives you the harmonic context; Target voices isolates the lines you're transcribing. Audio is generated as a WAV file and played using your device's native player.

3. Transcribe the notes

Use the pitch-and-time grid to enter notes. Click a cell to place a note at that pitch and onset. Set the note duration first; click an existing note to remove it. The grid uses quarter-note beats horizontally, and semitones vertically. Switch voices to transcribe different parts. Scroll horizontally for longer selections.
